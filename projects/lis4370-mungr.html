Custom R Package: Mungr

Date: 4/26/26

RESEARCH QUESTION

What common functions speed up the pre-processing phase in the exploratory data analysis phase? And can I create functions which suggest tips and eliminate steps based on qualities within the raw data?

RESULT

I created 5 core functions to speed up pre-processing steps:

  • get_advice(): Identifies common data quality issues (missing values, empty strings, case inconsistency, and inappropriate cardinality). It prints suggested cleaning actions to the console.
  • quick_clean(): Executes a predefined, sequential pipeline of text cleaning, type standardization, and imputation.
  • clean_text(): Trims whitespace, converts empty strings ("") to NA, and optionally standardizes case (lower, upper, title).
  • impute_missing(): Fills NA values using various strategies (mean, median, mode) for numeric columns, and a custom value (default: "Unknown") for character and factor columns.
  • standardize_strcols(): Attempts to coerce character columns to Date, Numeric, or Factor based on content and predefined thresholds.
  • standardize_numcols(): Converts numeric columns to optimal types, such as Logical (for 0/1 data), Factor (for low-cardinality data), or Integer (for memory optimization).

Why these functions? These functions represent common pre-processing steps in the early phases of data cleaning and allows users to quickly transform part or all of their features without dealing with long tidyr pipelines.

ABOUT

Data cleaning takes up two-thirds of the data analysis pipeline. As part of my final project for LIS4370, I created a package for beginners to quickly gain insights, suggestions, and clean their dataframes. As someone who spends a majority of their time finding the best ways to clean messy datasets, I wanted to create a package that gave generic advice on common data quality issues for dataset features, such as high/low cardinality, missing values, and zero variance.

This package, however, is not intended for special cases. It is best used to gain insights, but not to replace human-made choices.
